# Think Like a Scientist | 像科学家一样思考

## Resource folder: how it is organised

Exported on 15 October 2026 from the designed slides and printables in Claude Design. Ten weeks for each of Years 7, 8 and 9, plus the language support pack, the assessment pack and the teacher documents.

### Folders

| Folder | What is inside |
|---|---|
| `00_Read_me` | This page, and the list of layout corrections made in these files. |
| `01_Teacher_documents` | Teacher Guide, Programme Outline, Language Access Policy (Years 7 and 8), Glossary (Years 7 and 8), Tracker guide, the tracker workbook and the science requisition workbook (Excel). |
| `02_Language_support_Y7_Y8` | Language support pack (instruction words key, classroom language card, frame banks, role cards, poster) and My Science Dictionary. |
| `03_Assessment` | Rubric, certificates and skills reports. The Week 1 skills checks and interest survey are in each year's Week 1 printables; the Week 5 checkpoints are in each year's Week 5 printables. |
| `Year_7_Ice_Engineers` | One folder per week. |
| `Year_8_Science_Detectives` | One folder per week, plus the Case Bible (teacher only, never give to students). |
| `Year_9_Claim_Busters` | One folder per week. |

### Inside each week folder

| File | Use it for |
|---|---|
| `..._Slides.pptx` | Editing in PowerPoint. Every text box, picture and speaker note is editable. |
| `..._Slides.pdf` | Projecting or sharing when no editing is needed. Looks exactly like the design. |
| `..._Printables.pdf` | Printing: worksheets, kit card, cards and any other printables for that week, each page at its own paper size (mostly A4; kit cards and logbook pages are A5). |
| `..._Lesson_file.pdf` | The full lesson file for the teacher: lesson plan, timings, answer key and handover notes. |

### Notes

- **PowerPoint fonts.** The PowerPoint files use Arial and Garamond, which come with Microsoft Office, so they look the same on any school computer. The PDFs use the programme fonts (EB Garamond and Noto Sans). If you edit a slide in PowerPoint, the PDF will not change: save a new PDF from PowerPoint (File, Save As, PDF).
- **Small PowerPoint differences.** A few details convert imperfectly to PowerPoint, and the PDFs show the intended design: on the Year 8 exit-ticket slides the goal numbers sit against their tick boxes; the ruled notebook lines behind the sentence frames on Year 8 Week 1 slide 10 are missing; and a few labels or titles wrap onto a different number of lines. Nudge them in PowerPoint if they matter to you.
- **Printing.** Print printables at 100% ("Actual size"), not "Fit to page", so A5 cards stay A5. Print the Year 8 pH colour chart in colour and laminate it.
- **Chinese text.** All Chinese is marked "draft, needs native-speaker check". Check before printing class sets.
- **Layout corrections.** About 100 layout faults found during the export (text pushed to the slide edge on cover slides, safety rules drawn over the title on Safety slides, footers and table rows cut off at the bottom of printable pages, and a few smaller ones) are corrected in these files. No wording was changed. The live Claude Design pages still have these faults until they are rebuilt or corrected there. See `Corrections_list.pdf`.
- **If a deck is rebuilt in Claude Design later,** these files will be out of date for that week. Use the Download button on that deck (PowerPoint or PDF), or ask for a fresh export.
