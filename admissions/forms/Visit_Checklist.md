# Visit checklist: one sheet for each student

[[namegrid:Student name,Candidate number,Year group applied for,Date of visit,Assessor,Interviewer]]

**For the admissions office.** Print this sheet with the student's papers and tick each line as it is done. When every box is ticked, the visit is complete. Nothing here needs a computer until the last section.

#### Before the visit

| Done | What | Notes |
|---|---|---|
| [[tick]] | Application, ID page, two years of school reports and the signed consent are in the file | |
| [[tick]] | Homeroom teacher reference sent to the current school (folder **4 Send before the visit**) | Date sent: |
| [[tick]] | Visit booked. Family told how long it takes and to bring glasses or hearing aids | |
| [[tick]] | Assessor booked. Interviewer booked for the same day (usually the principal) | |
| [[tick]] | Printed from the year group folder, **1 Print one per student**: every file, double-sided | |
| [[tick]] | Candidate number written on every printed sheet | |
| [[tick]] | Room ready: quiet, a clock, pencils and rubber; counters and crayons (Years 1 and 2); a calculator (Years 9 to 12) | |
| [[tick]] | Recording copied from **3 Listening recording** to the laptop or phone; speaker tested | |
| [[tick]] | The staff folder for the year (**2 Print once**) is in the room | |

#### On the day

| Done | What | Hand to |
|---|---|---|
| [[tick]] | Family welcomed; parents shown where to wait | |
| [[tick]] | Student paper and the **student record** (one booklet) | the **assessor** |
| [[tick]] | Parent conversation record; conversation held while the student works | the **staff member** talking to the parents |
| [[tick]] | The student record, with Part A and the top of Part B filled in, before the interview | the **interviewer** |
| [[tick]] | Family thanked. **No results given on the day** | |
| [[tick]] | Collected back: the marked student paper, the student record (Parts A to C complete), the parent conversation record | **admissions** |

#### After the visit

| Done | What | By |
|---|---|---|
| [[tick]] | Student record Parts A to C complete and signed | the same day |
| [[tick]] | Anything worrying reported to the Designated Safeguarding Lead | the same day |
| [[tick]] | Part D of the student record (the decision) completed | within two working days |
| [[tick]] | Decision confirmed by the Head of School or Deputy (signature in Part D) | |
| [[tick]] | Student entered in the tracker (year group sheet, one row; status updated at each step) | |
| [[tick]] | Assessment result and report completed; family told, starting with the student's strengths | Date told: |
| [[tick]] | Report given with the marked papers; everything filed together in the secure admissions folder | |
