# Parent conversation record

[[namebox:Candidate name,Year group applied for,Date,Staff member,Parents or carers present,Language used (and interpreter if any)]]

**About 15 minutes.** Hold it while the student does the written tasks with another adult, or straight after. Use the family's preferred language; a Chinese-speaking colleague should lead or interpret if the staff member does not speak Chinese. The aim is a two-way conversation: to understand the child and the family's hopes, to explain how the international programme works, and to check that what the family wants matches what the school offers. Do not discuss the assessment results on the day.

## 1. Why the international programme?

| Question | Notes |
|---|---|
| Why are you looking for a place in the international programme, and why now? | |
| What do you know about how the programme works (lessons in English, the UK-style curriculum, assessment, homework, activities)? | |
| Whose idea is the move, and how does your child feel about it? | |

## 2. Schooling so far

| Question | Notes |
|---|---|
| Schools attended, years, and type (Chinese mainstream, bilingual, international, overseas) | |
| Any year repeated or skipped? Any long gaps? | |
| Why is the child leaving their current school? | |
| Student registration (学籍): where is it held now, and what will happen to it? (admissions office to give the school's position) | |
| School reports, certificates and any assessments the family can share | |

## 3. Languages

| Question | Notes |
|---|---|
| Which languages are spoken at home, and by whom? | |
| How has the child learnt English so far (school lessons from which grade, classes outside school, tutor, online, time abroad, English-speaking carer)? About how many hours a week? | |
| Does the child read in English at home? In Chinese? | |
| How will the family support English at home (reading, media, activities), and support Chinese if that matters to the family? | |

## 4. Learning, health and development

Ask gently and explain why: the school wants to have the right support ready from the first day.

| Question | Notes |
|---|---|
| What is your child good at? What do they enjoy most? | |
| Has any teacher or doctor ever raised a concern about learning, speech and language, attention, behaviour, hearing or vision? Any assessments or reports? | |
| Any extra help at the current school? | |
| Medical conditions, allergies, medication (also on the school medical form) | |
| For young children: speech in Chinese for their age, toilet and self-care, sleep | |

## 5. Wellbeing and the week

| Question | Notes |
|---|---|
| How would you describe your child's personality? How do they cope with change? | |
| Friendships: does your child make friends easily? | |
| A typical weekday and weekend: after-school classes, tutoring, sport, music, screen time, sleep | |
| Any big changes in the family recently (a move, a new baby, a parent working away)? Share only what you are comfortable sharing. | |

## 6. Expectations and partnership

| Question | Notes |
|---|---|
| What would make this a successful first year for your child? | |
| What do you expect from the school (homework, reports, communication, class rankings, exam results)? Explain how the school reports progress and how it communicates. | |
| How does the family feel about co-curricular activities, sport, arts, service and wellbeing as part of education, not just exam subjects? | |
| Learning in a new language takes time: explain what is typical (social English often within one to two years; the English needed for academic work often takes several years) and how the school supports it. How does the family feel about this? | |
| How would the family like to be involved (events, meetings, volunteering)? | |

## 7. Future plans

| Question | Notes |
|---|---|
| What are your hopes for your child in the long term (university, country, career)? | |
| Do you plan to stay in the international programme through to the end of school? | |
| Explain the programme's pathway (for example IGCSE, then the sixth form programme) and how it differs from the 中考 and 高考 route, using the admissions office's wording. Does the family understand that moving back to the national exam route later may not be straightforward? | |
| Year 10 applicants: which IGCSE subjects does the student hope to take? Explain that IGCSE is a two-year course starting in Year 10. | |

## 8. Boarding (only if the child will board)

| Question | Notes |
|---|---|
| Has the child stayed away from home before (camps, boarding, family)? How did it go? | |
| How independent are they with daily routines, sleep and belongings? | |
| How will the family keep in touch, and how often will the child go home? | |
