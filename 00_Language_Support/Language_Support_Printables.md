Series: Years 7 and 8 (one version serves both unless stated) | Print before the next lesson, then reuse all term
Chinese text status: draft, needs native-speaker check

These are the "extras" from `Language_Access_Policy.md`, Section 8. Each block marked **[Paste into Claude Design]** is self-contained.

## 0. What is here and when to print it (for the teacher)

| Item | Size | Copies per class | When | Used for |
|---|---|---|---|---|
| 1. Instruction words key 指令词 | A3 poster, plus a strip that lives on the worksheet template | 1 poster per room | Before the next lesson | Students decode "tick, circle, match, measure" without asking |
| 2. Classroom language card 课堂用语卡 | A5, two sides, laminated; plus A3 poster of side B | 1 card per student, 1 poster per room | Before the next lesson | Routine phrases and "how to ask for help" |
| 3. Sentence frame bank 句型框架 | A4 poster per series; A6 cards, one set per group | 1 poster, 6 card sets | Before the next lesson | Reporting back in English |
| 4. Group role cards with duties | Business-card size, 6 cards per set, laminated | 6 sets | Replace existing role cards when printed | Roles explained in both languages |
| 5. Think in any language poster | A3 | 1 per room | Before the next lesson | Reminds students and visitors how we judge work |
| My Science Dictionary 我的科学词典 | A5 booklet | 1 per student plus 4 | Week 1, or the next lesson | See `My_Science_Dictionary_Y7.md` and `_Y8.md` |

Hand the Instruction words key and the Classroom language card out with a two-minute walk-through: point to a word, say it in English, a student says the Chinese, the class does the action (tick in the air, circle in the air). Repeat the walk-through in the Do Now of the following two lessons.

## 3. Sentence frame bank 句型框架 [Paste into Claude Design]

### 3a. Year 7 Ice Engineers

Create an A4 portrait, black-and-white-printable poster "Sentence frames 句型框架 | Ice Engineers 冰雪工程师" using the Think Like a Scientist design system, Ice Engineers series, and the same content as a set of A6 cards (one frame per card, 4 cards per A4 sheet, cut lines). Each frame: English frame in bold with the gaps as "___", the Chinese frame beneath in the lighter weight, then one filled example in a lighter italic. Print 1 poster per room and 6 card sets per class (one per group table).

| Week | English frame | 中文句型 | Example |
|---|---|---|---|
| 1 | I observe ___. | 我观察到___。 | I observe four large paw prints. |
| 1 | I infer ___ because ___. | 我推断___，因为___。 | I infer a fox walked here because the prints have four toes. |
| 2 | I predict ___ because ___. | 我预测___，因为___。 | I predict the heavy ball lands first because gravity pulls it more. |
| 2 | If ___, then ___. | 如果___，那么___。 | If there is no air, then both balls land together. |
| 3 | It is / is not fair because ___. | 它公平／不公平，因为___。 | It is not fair because they drop from different heights. |
| 3 | I change ___. I measure ___. I keep ___ the same. | 我改变___。我测量___。我保持___不变。 | I change the wing length. I measure the fall time. I keep the drop height the same. |
| 3 | We must keep ___ the same because ___. | 我们必须保持___不变，因为___。 | We must keep the drop height the same because higher drops take longer. |
| 4 | The anomaly is ___ because ___. | 异常值是___，因为___。 | The anomaly is 4.9 s because the other times are about 2.5 s. |
| 4 | I will leave it out of the mean because ___. | 我算平均值时不用它，因为___。 | I will leave it out of the mean because one wrong reading would move the mean. |
| 8 | ___ is an anomaly because ___. | ___是异常值，因为___。 | 150 ml is an anomaly because the other strips held about 300 ml. |
| 5 | As the ___ increases, the ___ increases / decreases. | 随着___增加，___增加／减少。 | As the wing length increases, the fall time increases. |
| 5 | Our results show ___. | 我们的结果显示___。 | Our results show longer wings fall more slowly. |
| 6 | I think ___ because ___. | 我认为___，因为___。 | I think wool keeps the ice frozen longest because it traps air. |
| 9 | One problem was ___. Next time we would ___. | 一个问题是___。下次我们会___。 | One problem was air bubbles in the ice. Next time we would tap the moulds. |
| 9 | We are confident / fairly confident / not confident because ___. | 我们很有把握／比较有把握／没有把握，因为___。 | We are fairly confident because our three repeats were close. |
| 9 | If I did it again, I would ___. | 如果再做一次，我会___。 | If I did it again, I would freeze every strip for the same time. |

### 3b. Year 8 Science Detectives

Create an A4 portrait, black-and-white-printable poster "Sentence frames 句型框架 | Science Detectives 科学侦探" using the Think Like a Scientist design system, Science Detectives series, and the same content as a set of A6 cards (one frame per card, 4 per A4 sheet, cut lines). Same layout as 3a. Print 1 poster per room and 6 card sets per class. Examples use the case but give away nothing about the solution.

| Week | English frame | 中文句型 | Example |
|---|---|---|---|
| 1 | I observe ___ at square ___. | 我在___格观察到___。 | I observe white powder at square F4. |
| 1 | I infer ___ because ___. | 我推断___，因为___。 | I infer someone stood by the desk because there is a footprint. |
| 1 | This is an opinion because ___. | 这是观点，因为___。 | This is an opinion because we cannot test "he looks kind". |
| 2 | My fingerprint is a ___ because the lines ___. | 我的指纹是___，因为纹线___。 | My fingerprint is a loop because the lines go in and back out the same side. |
| 2 | This evidence is strong / weak because ___. | 这个证据有力／薄弱，因为___。 | This evidence is weak because loops are very common. |
| 3 | This sample matches ___ because ___. | 这个样本与___匹配，因为___。 | This sample matches reference 2 because the bands are the same colours in the same order. |
| 4 | ___ is ruled out because ___. | ___被排除，因为___。 | Sample C is ruled out because it does not match the scene sample. |
| 5 | The evidence shows ___. This supports / does not support ___ because ___. | 证据显示___。这支持／不支持___，因为___。 | The evidence shows the powder dissolves. This does not support chalk because chalk does not dissolve. |
| 6 | We estimate ___ because ___. | 我们估计___，因为___。 | We estimate a height of about 180 cm because the foot length is 27 cm. |
| 7 | I change ___. I measure ___. I keep ___ the same. | 我改变___。我测量___。我保持___不变。 | I change the soil sample. I measure the layer height. I keep the water volume the same. |
| 7 | I predict ___ because ___. | 我预测___，因为___。 | I predict the playground soil will match because it is sandy. |
| 9 | One problem with this evidence is ___. | 这个证据的一个问题是___。 | One problem with this evidence is that the print is smudged. |
| 9 | We are confident / fairly confident / not confident because ___. | 我们很有把握／比较有把握／没有把握，因为___。 | We are fairly confident because three clues point the same way. |
| 9 | To be more confident, we would need ___. | 要更有把握，我们需要___。 | To be more confident, we would need a clearer fingerprint. |
| 10 | Our verdict is ___ because ___. | 我们的裁决是___，因为___。 | Our verdict is ___ because every reliable clue matches. |

## 4. Group role cards with duties [Paste into Claude Design]

Create a set of six business-card size (85 mm by 55 mm) role cards for the Think Like a Scientist programme, using the Think Like a Scientist design system, programme wordmark only, black-and-white printable, 6 cards per A4 sheet with cut lines. Each card: role icon at top left, role name in bold English with Chinese beside it, then three duty lines, each English with the Chinese beneath in the lighter weight. Minimum 9 pt. Laminate. Print 6 sets per class.

**Card 1: Lead Scientist 首席科学家** (icon: a clipboard with a star)
- Keeps the group on task and on time. 让小组专注任务、按时完成。
- Makes sure everyone has a job. 确保每个人都有任务。
- Asks the teacher if the group is stuck. 小组卡住时去问老师。

**Card 2: Measurer 测量员** (icon: a ruler and stopwatch)
- Takes the readings. 负责读数。
- Uses the tool the same way every time. 每次用同样的方法使用工具。
- Says the number clearly for the Recorder. 把数字清楚地告诉记录员。

**Card 3: Recorder 记录员** (icon: a pencil on a table grid)
- Writes results in the table, with units. 把结果和单位写进表格。
- Writes straight away, never from memory. 立即记录，不靠记忆。
- Marks any result that looks odd. 标出看起来异常的结果。

**Card 4: Safety Officer 安全员** (icon: safety goggles)
- Checks the kit card and the safety rules. 检查器材卡和安全规则。
- Watches for spills and hazards and tells the teacher. 注意溢出和危险，并告诉老师。
- Leads the clean-up. 带领收拾整理。

**Card 5: Reporter 汇报员** (icon: a speech bubble)
- Shares the group's findings with the class. 向全班汇报小组发现。
- Uses the English frame and three key words. 使用英语句型框架和三个关键词。
- Checks the group agrees before speaking. 发言前确认小组意见一致。

**Card 6: Language buddy 语言伙伴** (icon: two heads, one speech bubble between them; this card is held by a Band 3 student paired with a Band 1 student, in addition to their group role)
- Explains the task in Chinese. 用中文解释任务。
- Does not write the answer for the buddy. 不替伙伴写答案。
- Helps the buddy say it in English. 帮伙伴用英语说出来。

Footer on every card: "Roles change every week. 角色每周轮换。"

## 5. Think in any language poster [Paste into Claude Design]

Create an A3 portrait, black-and-white-printable poster for the Think Like a Scientist programme, using the Think Like a Scientist design system, programme wordmark only. Three large lines, each English in bold with Chinese beneath in the lighter weight, with the "any language" thought-bubble icon large at the top. Print 1 per room.

- Think in any language. 思考可用任何语言。
- Science words in English. 科学词汇用英语。
- We judge the science, not the English. 我们评价的是科学思维，不是英语语法。

Small footer line: "Ask. Try. Change your mind when the evidence says so. 提问。尝试。证据说变，就改变想法。"
